# College Canteen Ordering and Billing System

A Java Swing and MySQL desktop application for managing college canteen menus, customer orders, billing, payments, and food stock.

## Features
- View menu items, prices, and available stock
- Add multiple food items to a shopping cart
- Calculate order totals and generate bills
- Save orders and payments in MySQL
- Automatically update stock after checkout
- Display food images in the menu

## Technologies
- Java
- Java Swing
- MySQL
- JDBC
- VS Code

## Requirements
- JDK 8 or later
- MySQL Server
- MySQL Connector/J

## Setup
1. Install Java and MySQL.
2. Clone or download this repository.
3. Run `database.sql` in MySQL Workbench.
4. Configure your local database username and password.
5. Configure the MySQL Connector/J dependency.
6. Compile and run `CanteenApp.java` using the instructions for your configured Java version.

## Database
The application uses four main tables:
- Menu
- Orders
- OrderItems
- Payments
